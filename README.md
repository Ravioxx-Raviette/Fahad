FAHAD (Deepfake Image Verification Application)FAHAD is an offline, AI-powered mobile application designed to detect AI-generated and manipulated images (deepfakes). By leveraging a locally deployed Vision Transformer (ViT) model converted to TensorFlow Lite (TFLite), FAHAD performs high-accuracy image verification directly on the user's device—requiring zero cloud interaction or internet connectivity.In an era of rising digital misinformation and cloud privacy vulnerabilities, FAHAD provides a secure, fast, and privacy-preserving shield against visual manipulation.Key Features100% Offline Verification: Analyze images anytime, anywhere—even in zero-connectivity environments.Privacy-First Architecture: No cloud dependencies. Images never leave your device; all processing occurs locally in a sandboxed environment.AI-Powered Analysis: Utilizes an optimized Vision Transformer (ViT) to deliver a Credibility Score (%), a clear Classification (Authentic vs. Manipulated), and a detailed breakdown.Local History Dashboard: Automatically saves verification history (scores, metrics, and timestamps) locally using SQLite for quick review.Universal Formats: Supports standard image formats, including .jpg, .jpeg, and .png.Tech StackComponentTechnologyRoleFrontend UIFlutterCross-platform mobile development (iOS/Android)LanguagesDart & PythonDart for application workflow; Python for model optimizationCore AI ModelVision Transformer (ViT)Advanced deep learning architecture for image classificationInference RuntimeTensorFlow Lite (TFLite)Embedded engine for lightning-fast on-device executionLocal StorageSQLiteLight relational database for offline report loggingSystem ArchitectureFAHAD is built on a linear pipeline designed for minimal latency and maximum data isolation:[User Interface (Flutter)]

Interface BlueprintThe user interface is built across three primary views:Main Screen (mainscreen): The clean entry point featuring image upload zones, a camera capture button, and current scanning states.Verification Summary (result1, result2): Displays instant high-level metrics, including the binary authenticity badge (Authentic / Manipulated), the Credibility Score, and extracted image metadata (EXIF).Detailed Report (result3): Houses the AI Analysis Summary alongside historical trends retrieved from the local database.Security & Privacy GuardrailsData Isolation Guarantee: FAHAD does not require internet permissions. It does not use external APIs, tracking cookies, or remote analytical telemetry. Your files, metadata, and results remain entirely yours.
